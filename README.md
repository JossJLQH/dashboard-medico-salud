# 🏥 Dashboard Clínico & Hospitalario

Aplicación web interactiva desarrollada con **Python**, **Dash** y **Plotly** para el monitoreo y análisis de métricas hospitalarias en tiempo real.

---

## 🚀 Características Principales
* **Tendencia Semanal de Ocupación:** Gráfica de líneas interactiva para el seguimiento de la ocupación porcentual diaria en el hospital.
* **Distribución por Departamentos:** Gráfica de barras detallada del flujo de pacientes en áreas clave como Urgencias, UCI, Pediatría, Cardiología y Ortopedia.
* **Interfaz Moderna (Dark Mode):** Diseño visual limpio, estético y adaptado a estándares modernos de experiencia de usuario.

---

## 🛠️ Tecnologías y Librerías Utilizadas
* **Python:** Lenguaje de programación principal.
* **Dash & Plotly:** Framework de desarrollo web y motor de gráficas interactivas.
* **Pandas:** Estructuración, limpieza y manipulación de conjuntos de datos.
